01 / HARDWARE

مكونات الكمبيوتر

المعلومة مكتوبة أمامك مباشرة. لا تحتاج لفتح كارت لمعرفة المفهوم.

🧠

CPU — المعالج

ينفذ التعليمات ويعالج البيانات. الأنوية تنفذ العمل بالتوازي، والـCache ذاكرة صغيرة وسريعة تقلل زمن الوصول للبيانات المتكررة.

🧩

RAM — الذاكرة

مساحة عمل مؤقتة للبرامج والبيانات أثناء التشغيل. عند فصل الكهرباء تفقد محتواها، وزيادتها تساعد على تشغيل برامج أكثر في الوقت نفسه.

🎮

GPU — كارت الشاشة

يعالج الرسوميات والمهام المتوازية. في الجهاز المتقدم يمكن استخدام بطاقة مثل RTX 5090، لكن يجب مراعاة الطاقة والحجم والتوافق.

🧱

Motherboard — المازربورد

اللوحة التي تربط CPU وRAM وGPU والتخزين والطاقة. تحتوي على Socket وDIMM وPCIe وM.2 وموصلات الطاقة.

💾

NVMe SSD — التخزين

وحدة تخزين سريعة تتصل غالبًا عبر M.2 وPCIe. تحفظ النظام والبرامج والملفات حتى بعد إيقاف الجهاز.

🔌

PSU — مزود الطاقة

يحوّل الكهرباء ويوزعها على المكونات. من أهم التوصيلات 24-Pin للوحة وEPS للمعالج وكابل طاقة GPU للبطاقة.

❄️

Cooling — التبريد

المعالج وكارت الشاشة ينتجان حرارة. المشتت والمراوح أو التبريد المائي ينقلان الحرارة بعيدًا عن المكونات.

🖥️

Case — الكيس

يحمي القطع وينظم الهواء والكابلات. يجب اختيار حجم يدعم اللوحة وكارت الشاشة ومبرد المعالج ومزود الطاقة.

03 / REAL BUILD ORDER

ترتيب التجميع الحقيقي

المحاكاة تتبع منطق التجميع الفعلي، وليس مجرد وضع صور فوق بعضها.

01

CPU

افتح Socket، حاذِ العلامة، وضع المعالج بدون ضغط جانبي.

02

RAM

حاذِ الـnotch مع الشق، ثم اضغط حتى تغلق المشابك.

03

M.2 SSD

أدخل الوحدة بزاوية ثم اخفضها وثبتها بالبرغي أو الآلية المخصصة.

04

Cooler

استخدم كمية مناسبة من المعجون الحراري وثبت المشتت بالتساوي.

05

GPU

افتح PCIe x16، أدخل البطاقة بشكل مستقيم وثبتها في الكيس.

06

PSU

ثبت مزود الطاقة ثم وصل 24-Pin وEPS وكابل GPU بالطريقة الصحيحة.
